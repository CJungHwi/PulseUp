# Electron 앱 로그 분석 보감 (2026-04-12)

## `[LOG] 0` 대량 출력

- **현상**: 파일 로그에 `[LOG] 0` 한 줄이 매우 많이 반복될 수 있음.
- **의미**: 메인 프로세스에서 `console.log`의 **단일 인자가 숫자 `0`**일 때 `file-logger`가 `[LOG] 0`으로 기록함.
- **소스 코드**: 저장소 내에는 `console.log(0)` 형태의 직접 호출은 확인되지 않음. 배포본(`app.asar`)·의존성(ANT/USB)·과거 빌드 잔존 가능성이 있음.
- **대응**:
  - 심박 **UI 브로드캐스트**는 유지하되, **유효하지 않은 HR(0)** 은 서버 업로드 버퍼에 넣지 않음 → 로그·API 부하 감소.
  - 세션 **401** 시 심박 배치 업로드를 일정 시간 **백오프** → 동일 에러 로그 폭주 방지.
  - ANT+ 심박 **틱 단위 `log()`** 호출 제거(옵션 환경변수로만 상세 로그).

## 콜드 스타트 화면 끊김
